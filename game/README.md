# 삼한난세 — 플레이 가능한 프로토타입

후삼국시대 2D 탑다운 생존 액션 게임의 최소 플레이 버전입니다. 기획 전체는 [`docs/GAME_DESIGN.md`](../docs/GAME_DESIGN.md)에 있습니다.

## 실행
ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고 간단한 웹 서버로 여세요.

```bash
cd game
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 조작
- 이동: WASD · 방향키, 터치는 화면을 누른 채 끌기
- 공격: 자동
- 책략 선택: 클릭 · 탭 또는 1 · 2 · 3
- 일시정지: P · Esc
- 소리 켜고 끄기: M 또는 화면의 '소리' 버튼
- 빠른 시험 모드: 타이틀에서 체크하면 1분 뒤 보스가 나옵니다

## 들어 있는 것
- 영웅 3명: 왕건(검, 통솔, 신숭겸 소환, 말타기), 견훤(대도, 패왕의 일격, 궁수를 끌어오는 철쇄 — 근접 전용이지만 가장 강함), 궁예(석장 원거리 공격 + 금강저, 관심법). 무기마다 4단계 진화
- 전장 4개: ★1 서남해 갯벌(수달 능창), ★2 공산 동수(견훤 / 견훤으로 하면 신숭겸), ★3 고창 병산(김악 / 유금필), ★4 철원 궁성(궁예 — 낙뢰·광배·분신·순간이동 / 궁예로 하면 개국 4공신 넷이 한꺼번에)
- 적: 창병, 궁수, 해적, 기마병, 강화 적 4종(철갑병, 방패병, 정예 궁수, 정예 기마병), 군량 수레
- 공훈 엽전과 레벨업, 책략 3택 1 (영웅 전용 책략 포함), 기세 게이지
- 역사 이벤트: 해적 기습, 포위, 신숭겸의 대역
- 합성 사운드: 효과음과 장구 장단 배경 리듬
- 판 밖 성장: 판마다 냥을 벌고(난이도 별이 높을수록 많이), 상점에서 장비·수련·비전을 산다. 장비는 부위마다 범품~국보 5등급(높은 등급은 어려운 전장을 깨야 해금)이고 +5까지 제련(갈수록 실패 확률 상승). ★2·★3·★4는 각각 양품·상품·진품 이상 장비 3부위를 입어야 출진 가능. 브라우저에 저장
- 영웅 빌드: 영웅마다 두 갈래 스킬 트리와 보물(아이템) 트리. 같은 영웅도 길에 따라 다르게 싸운다

## 코드 구조
```
src/
  main.js        부팅, 화면 전환, 프레임 루프
  game.js        월드 상태, 피해·처치·레벨업·보스 전환
  core/          입력(키보드·터치 스틱), 수학, 공간 해시
  data/          영웅 · 무기 · 적 · 보스 · 스테이지 · 책략 정의 (콘텐츠는 여기만 고치면 됨)
  systems/       무기 패턴, 고유기, 아군, 적 행동, 보스 패턴, 스폰 시간표
  render/        카메라와 그리기 순서, 캐릭터 그림, 지형
  ui/            HUD, 타이틀·레벨업·결과 화면
  audio/         WebAudio 효과음과 장단
```

새 영웅·적·보스·스테이지를 넣는 방법은 기획서 10장 "확장 방법" 표를 보세요.
