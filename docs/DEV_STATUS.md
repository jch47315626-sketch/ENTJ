# 삼한난세 (三韓亂世) — 개발 현황 요약

> 이 문서는 다른 AI 어시스턴트나 새 협업자에게 지금까지의 개발 상황을 한 번에 설명하기 위한 요약입니다.
> 자세한 기획은 `docs/GAME_DESIGN.md`, 실행 방법은 `game/README.md`에 있습니다.

---

## 1. 한 줄 소개

후삼국 시대(900~936)를 배경으로 한 **2D 탑다운 생존 액션 게임**입니다. 영웅 하나를 골라 5분 동안 몰려오는 적을 버티고, 마지막에 나오는 역사 속 적장(보스)을 쓰러뜨리면 전장을 평정합니다. 판마다 번 돈(냥)으로 장비와 스킬을 사서 더 어려운 전장에 도전하고, 마지막 전장 일리천(936)을 깨면 통일 엔딩이 나옵니다.

- 플레이: https://claude.ai/artifact/WR5CJqzV29xQUch57kdw8i ("링크가 있는 누구나" 공유)
- 저장소: `jch47315626-sketch/entj`, 작업 브랜치 `claude/upbeat-ritchie-oh5i49`
- 기존 게임을 베끼지 않도록 고유 시스템(기세 게이지, 영웅별 고유기, 역사 이벤트, 관심법 등)을 중심으로 설계했습니다.

## 2. 기술 스택과 실행

| 항목 | 내용 |
|---|---|
| 언어/런타임 | 순수 HTML5 + Canvas 2D + ES Modules (빌드 도구·외부 라이브러리 없음) |
| UI | 캔버스 위에 DOM 오버레이 |
| 사운드 | Web Audio로 합성한 효과음과 장구 장단 배경 리듬 (음원 파일 없음) |
| 그림 | 모든 캐릭터, 아이템 아이콘, 지형을 Canvas 코드로 직접 그림 (이미지 파일 없음) |
| 글꼴 | Google Fonts: Jua(제목), Gowun Dodum(본문) |
| 저장 | 브라우저 `localStorage` 키 `samhan-save-v1` + 세이브 코드 내보내기/불러오기 |
| 실행 | `cd game && python3 -m http.server 8765` 후 `http://localhost:8765` |
| 테스트 | Playwright(헤드리스 Chromium)로 봇이 자동 플레이하는 밸런스 시뮬레이션 |

## 3. 폴더 구조

```

  src/
    main.js           부팅, 화면 전환, 프레임 루프, 상점/트리 구매 처리
    game.js           월드 상태: 피해, 처치, 레벨업, 보스 전환, 보상 계산
    core/             입력(키보드·터치), 수학, 공간 해시, 저장(save.js)
    data/             ★ 콘텐츠 정의 — 대부분의 수정은 여기서
      heroes.js       영웅 3명
      weapons.js      무기(영웅당 4단계 + 진화)
      enemies.js      일반 적 9종
      bosses.js       보스 + 2단계 보스 + 그룹 보스
      stages.js       전장 5개(난이도, 시간표, 이벤트, 출진 조건)
      upgrades.js     레벨업 책략
      skills.js       능동 스킬 단계표
      meta.js         냥, 장비(5등급), 제련, 수련, 비전, 출진 조건
      trees.js        영웅별 스킬 트리 + 보물 트리
      balance.js      시간에 따른 적 체력/피해 곡선
    systems/          무기 패턴, 고유기, 능동 스킬, 아군, 적 AI, 보스 패턴, 스폰
    render/           카메라·그리기 순서, 2등신 캐릭터, 지형, 아이템 아이콘
    ui/               HUD, 메뉴 화면 렌더링
    audio/            합성 사운드
docs/
  GAME_DESIGN.md      전체 기획서(세계관, 시스템, 표, 밸런스 기록)
  DEV_STATUS.md       (이 문서)
```

데이터 주도 구조입니다. 새 무기/적/보스/전장/책략은 `data/`에 항목을 추가하고, 필요하면 `systems/`의 레지스트리(PATTERNS, BEHAVIORS, BOSS_PATTERNS, SPECIALS, ACTIVE_SKILLS, GROUNDS)에 동작을 하나 추가하면 됩니다.

## 4. 핵심 게임 시스템

- **판 구조**: 5분 생존 → 보스전(원형 결투장). 전장마다 시간대별 적 구성과 역사 이벤트가 있습니다.
- **공훈(XP)과 책략**: 적이 떨군 엽전을 모아 레벨업하면 책략 3개 중 1개를 고릅니다(무예/병법/지세/보급).
- **기세 게이지**: 시간과 처치로 차오르고, 가득 차면 영웅 고유기가 자동 발동합니다.
- **무기 진화**: 주무기 4단계, 마지막 단계는 진화 무기입니다.
- **보스 패턴**: 모든 공격에 예고(빨간 범위, 돌진선, 부채꼴)가 먼저 나옵니다.
- **난이도 배율**: 전장별 `difficulty` 블록(적 체력·피해·스폰·정예 확률·보스 체력·피해)이 시간 곡선 위에 곱해집니다.

## 5. 영웅 3명

| 영웅 | 성격 | 주무기 → 진화 | 고유기(기세) | 전용 책략·스킬 |
|---|---|---|---|---|
| **왕건** | 균형형, 아군 소환 | 고려검 → 태조의 검(회전베기 + 검기) | **통솔**: 고려 창병 소환 (최근 2배 수, 피해 16, 0.5초 간격으로 강화) | 친위대, **신숭겸**(적을 끌어모으는 대역, 최종 단계는 죽을 때 폭발), **말타기**(초반 무적 + 지나간 자리 피해), 궁수대 |
| **견훤** | 근접 강타형, 가장 강함 | 대도 → 백제의 대도(3연타 + 충격파) | **패왕의 일격**: 전방 거대 참격 + 기절 | 패기, **철쇄**(원거리 적을 주기적으로 끌어옴), 궁수대 |
| **궁예** | 원거리 술사형 | 석장(법력구) → 미륵석장(관통 빛줄기) + 보조 무기 금강저(연쇄 번개) | **관심법**: 일반 병사를 홀려 서로 싸우게 함(영웅·보스 제외, 단계별로 수·등급 증가) | **마구니**(최근 추가: 주위를 도는 도깨비가 투사체를 막고 약한 피해), 관심법 강화 |

기본 능력치:
- 왕건: 체력 120 / 이동 155 / 위력 ×1.0 / 갑주 0
- 견훤: 체력 160 / 이동 142 / 위력 ×1.3 / 공격 간격 ×1.1 / 갑주 2 (두 차례 하향)
- 궁예: 체력 110 / 이동 150 / 위력 ×1.0 / 범위 ×1.1

## 6. 전장 5개 (★ = 난이도, 보상 배율)

| # | 전장 (연도) | ★ / 보상 | 출진 조건(착용 장비) | 보스 (대체 보스) | 특징 이벤트 |
|---|---|---|---|---|---|
| 1 | 서남해 갯벌 (903~910) | ★1 쉬움 ×1 | 없음 | 수달 능창 | 해적 기습, 궁수대, 해적 기마대, 포위 |
| 2 | 공산 동수 (927) | ★2 보통 ×1.8 | 양품 이상 3부위 | 견훤 (견훤 선택 시 신숭겸) | 신숭겸의 대역, 방패진 |
| 3 | 고창 병산 (930) | ★3 어려움 ×3 | 상품 이상 3부위 | 김악 (견훤 선택 시 유금필) | 호족 궁수 합류, 철갑병 포위 |
| 4 | 철원 궁성 (918) | ★4 매우 어려움 ×4.5 | 진품 이상 3부위 | 궁예: 예측 낙뢰·광배·분신·순간이동 (궁예 선택 시 개국 4공신 4명 동시) | **관심법의 밤**(시야 축소 + 자객) |
| 5 | 일리천 (936) | ★5 극악 ×6.5 | 국보 이상 2부위 | 신검: 2단계 보스 (견훤·궁예 선택 시 왕건과 가상 결전) | 대규모 기병 돌격 ×2, 후백제 장수 항복(적이 일시 아군) → **통일 엔딩** |

보스 시스템은 2단계(`phase2`), 그룹 보스(`group`), 분신(`minion`)을 지원합니다.

## 7. 판 밖 성장 (메타 진행)

- **냥**: 판이 끝나면(승패 무관) 전과 × 난이도 보상 배율 × (1 + 재물운)만큼 받습니다. 전투 중 HUD에 실시간으로 표시됩니다.
- **장비**: 6부위(투구, 갑옷, 장신구, 팔찌, 허리띠, 신발) × 5등급 = 30종입니다.
  - 등급은 범품 → 양품 → 상품 → 진품 → 국보입니다.
  - 높은 등급은 해당 별 난이도의 전장을 깨야 상점에 풀립니다(★1 → 양품 … ★4 → 국보).
  - 가격대는 대략 100 / 500 / 1,500 / 4,500 / 11,000냥입니다.
- **제련**: 산 장비를 +1~+5까지 강화합니다. 단계당 기본 효과 +12%이고, 성공률은 100 / 80 / 60 / 40 / 25%입니다. 실패하면 냥만 사라집니다.
- **수련**: 모든 영웅 공통입니다(무예, 체력, 기마, 재물운, 병법서).
- **비전**: 영웅별로 특정 스킬을 들고 출진합니다.
- **영웅 빌드**: 영웅마다 스킬 트리(뿌리 1개 + 갈래 A/B 중 하나만, 각 3단계)와 보물 트리(보물 칸 전용 아이템)가 있습니다. 갈래는 냥 90%를 돌려받고 바꿀 수 있습니다.
  - 왕건: 통솔의 길 / 기마의 길
  - 견훤: 패왕의 길 / 철벽의 길
  - 궁예: 법력의 길 / 관심의 길
- **출진 조건**: "장비 없이 ★2도 못 깨게"라는 요구를 영웅 밸런스를 건드리지 않고 지키려고 만든 장치입니다.
- **저장**: 브라우저에 자동 저장됩니다. 상점의 **기록** 탭에서 `SAMHAN1-…` 세이브 코드를 복사하거나 붙여 넣어 기기를 옮길 수 있습니다(검사합으로 손상된 코드는 거부).

## 8. 아트와 UI

- **캐릭터**: 귀여운 2등신입니다.
  - 정면을 본 큰 머리에 눈, 볼터치가 있습니다.
  - 이동 방향으로 몸을 돌리고, 걸을 때 통통 튑니다. 위로 걸으면 뒤통수가 보입니다.
  - 판정 원보다 1.35배 크게 그립니다.
- **영웅 특징**:
  - 왕건: 붉은 깃 투구, 붉은 망토, 콧수염
  - 견훤: 금관, 덥수룩한 수염, 성난 눈썹, 큰 덩치
  - 궁예: 민머리, 금빛 광배, 한쪽 눈 안대
- **UI**: 메인 화면 탭(캐릭터 변경 / 상점 / 맵 변경)으로 구성합니다.
  - 캐릭터 화면은 장비창(인형 배치) / 스킬 트리 / 보물 탭입니다.
  - 상점은 장비(부위 칩) / 수련 / 비전 / 기록 탭입니다.
  - 각 화면이 거의 한 화면에 들어오게 정리했습니다.
- **지형**: 전장마다 다른 절차적 지형입니다. 갯벌, 가을 산, 얼어붙은 강, 석등 있는 궁궐 마당, 갈대 강가 평원이 있습니다.

## 9. 밸런스 현황 (봇 시뮬레이션 기준, 각 4~6판)

| 조건 | 왕건 | 견훤 | 궁예 |
|---|---|---|---|
| ★1 장비 없음 | 4/4 | 6/6 | 2/4 |
| ★2 중간 장비 | 4/4 | 4/4 | 2/4 |
| ★3 진품 장비 | 4/4 | 4/4 | 1/4 |
| ★4 진품 + 트리 | 3~4/4 | 4/4 | 3/4 |
| ★5 국보 + 트리 | 4/4 | 4/4 | 3/4 |

- **견훤**: 두 번 하향했지만 여전히 가장 강합니다. 사용자가 "영웅 밸런스는 건드리지 말라"고 해서 그대로 둔 상태입니다.
- **왕건**: 통솔 창병 강화 후 크게 좋아졌습니다.
- **궁예**: 궁수대 → 마구니 교체 후 약해졌습니다. 사용자의 "궁예가 많이 좋음"이 너무 세다는 뜻인지 마음에 든다는 뜻인지 **확인 대기 중**입니다.
- 봇은 근접 플레이에 유리하고 거리를 벌리며 싸우는 플레이는 서툴러서, 실제 궁예는 표보다 조금 나을 수 있습니다.

## 10. 사용자 요청 흐름 (지금까지의 주요 결정)

1. 기획서 10항목 → 최소 플레이 프로토타입 (왕건, 서남해 갯벌)
2. 견훤·궁예, 정예 적, 사운드 추가 → 초반 난이도 완화
3. 궁예를 원거리 마법사로 바꾸고, 금강저·석장·관심법 추가
4. 왕건 신숭겸(대역, 폭발), 말타기 추가 / 견훤은 근접 전용이지만 가장 강하게
5. 원거리 적 비율 축소, 다중 자동 공격 약화, 주무기 1.2배
6. 난이도 별 1~5개 체계와 난이도별 보상, 냥 경제·상점·장비 도입
7. 메인 탭 메뉴, 캐릭터 선택과 인형식 장비창, 견훤 철쇄
8. 전장 ★3 → ★4 → ★5 순서로 추가, 영웅별 스킬/보물 트리, 견훤 하향 2회
9. 장비 5등급 세분화, 제련, 출진 조건(장비 없이 ★2 불가)
10. 귀여운 2등신 아트, 둥근 UI
11. 스크롤 줄이기(탭화, 맵 설명 삭제), ★1 상향
12. 세이브 코드 → 궁예 마구니, 왕건 창병 2배·강화

## 12. 협업 규칙 (지금까지 지켜 온 것)

- 사용자는 한국어로 요청하고, 결과도 한국어로 보고합니다.
- 변경 후에는 봇 시뮬레이션으로 수치를 확인하고, 스크린샷으로 화면을 확인한 다음 커밋 → 푸시 → 아티팩트 재배포 순서로 진행합니다.

- 콘텐츠 수치는 `data/` 파일에 모아 두고, 변경 이유와 테스트 결과는 `docs/GAME_DESIGN.md` 끝의 밸런스 기록에 남깁니다.
